# FinRoad

FinRoad — приложение для финансового плана: доходов, расходов, долгов и прогноза остатка. Текущая рабочая версия предназначена для macOS и сохраняет данные на компьютере без регистрации в FinRoad.

**[Попробовать демо](https://sad-jack.github.io/FinRoad/)** — вымышленные данные, изменения сбрасываются при перезагрузке.

## Запуск и сборка

Открой `output/FinRoad.app` или собери его командой `./macos/build.sh` на Mac с установленными инструментами командной строки Apple. Сборка подписана локально, без нотариального заверения Apple. Подробности — в [инструкции для macOS](macos/README.md).

Данные сохраняются в `~/Library/Application Support/FinRoad/`. Существующий JSON можно восстановить через «Импорт»; восстановление заменяет текущий план. В меню «Файл» можно подключить общий документ в iCloud Drive и отдельно настроить резервную копию. Мобильный клиент ещё не создан, а синхронизация между устройствами пока не проверена.

## Разработка

Исходники находятся в `app/` и `macos/`. Запуск проверок: `node --test tests/*.test.cjs`. [Архитектура и план синхронизации](docs/architecture.md) описывают границы работающей версии и ограничения синхронизации и работу для мобильного клиента.

`FinRoad.html` сохранён как прежняя браузерная версия; это не источник сборки приложения Mac. Изменения для приложения вносятся в `app/`.
