# FinRoad

FinRoad — приложение для планирования доходов, расходов и долгов с прогнозом остатка. Версии для Mac и iPhone работают с локальными данными и могут обмениваться планом через общий файл в iCloud Drive, без отдельной регистрации в FinRoad.

**[Попробовать демо в браузере](https://sad-jack.github.io/FinRoad/)**. На телефоне демо открывается с мобильным интерфейсом по образцу iPhone-версии и нижними вкладками «План», «Расход», «Приход» и «Ещё». В демо используются вымышленные данные. Изменения сбрасываются при перезагрузке страницы.

## Как установить FinRoad

**[Скачай ZIP с исходниками](https://github.com/Sad-Jack/FinRoad/archive/refs/heads/main.zip)** и распакуй его. Внутри будет папка `FinRoad-main`. Для сборки Mac и iPhone нужна вся папка. Готовых сборок в GitHub Releases пока нет.

### Mac

Нужен Mac с macOS 13 или новее.

1. Открой «Терминал» и выполни `xcode-select --install`, если инструменты командной строки Apple ещё не установлены. Дождись окончания установки.
2. Если распаковал архив в «Загрузки», выполни команды ниже. Для другой папки укажи её путь в первой команде.

   ```sh
   cd ~/Downloads/FinRoad-main
   bash macos/build.sh
   open output
   ```

3. В открывшейся папке `output` найди `FinRoad.app`, перетащи его в «Программы» и запусти оттуда.

[Подробнее о версии для macOS](macos/README.md).

### iPhone

Проект рассчитан на iPhone с iOS 16 или новее. Для установки нужен Mac с Xcode, который поддерживает версию iOS на телефоне. [Совместимость версий Xcode](https://developer.apple.com/xcode/system-requirements/).

1. На Mac открой `ios/FinRoad.xcodeproj` из распакованной папки. В **Xcode → Settings → Apple Accounts** (**Accounts** в старых версиях) войди в свой аккаунт Apple.
2. В настройках проекта выбери **Targets → FinRoad → Signing & Capabilities**. Нажми **Set Up Signing**, если Xcode показывает эту кнопку, или включи **Automatically manage signing**. Выбери свою команду в **Team** и задай уникальный **Bundle Identifier**, например `com.vashe-imya.finroad`. При следующих установках используй тот же идентификатор.
3. Подключи разблокированный iPhone к Mac кабелем и подтверди доверие компьютеру на телефоне, если появится запрос. В верхней панели Xcode выбери свой iPhone для запуска схемы **FinRoad**.
4. Если Xcode попросит включить режим разработчика, на iPhone открой **Настройки → Конфиденциальность и безопасность → Режим разработчика**, включи его и подтверди после перезапуска. [Инструкция Apple](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device).
5. Нажми **Run** (`⌘R`) в Xcode. После сборки FinRoad появится на iPhone.

При первом запуске подключи общий план с Mac по инструкции ниже или загрузи резервную JSON-копию FinRoad через **Ещё → Импортировать**.

Бесплатной **Personal Team** достаточно для установки на свой iPhone. Профиль подписи действует 7 дней, после чего снова запусти сборку и установку через Xcode. [Условия Apple](https://developer.apple.com/help/account/basics/about-your-developer-account/).

[Подробнее о версии для iPhone](ios/README.md).

### Windows

Отдельного приложения для Windows пока нет. Открой `FinRoad.html` из распакованного архива в обычном окне браузера. Это прежняя версия FinRoad. Она хранит план в браузере, поэтому открывай файл по тому же пути в том же профиле и сохраняй резервную копию через «Экспорт». Синхронизация с приложениями Mac и iPhone в этой версии недоступна.

### Android

Приложения для Android пока нет. На телефоне можно открыть [веб-демо](https://sad-jack.github.io/FinRoad/).

## Данные и синхронизация

На Mac план хранится в `~/Library/Application Support/FinRoad/`, на iPhone — в контейнере приложения. Чтобы открыть общий план, включи iCloud Drive на обоих устройствах.

1. На Mac открой **Файл → Настроить синхронизацию iCloud Drive…** и выбери папку в iCloud Drive. FinRoad использует файл `FinRoad-sync.json` в этой папке.
2. Когда файл появится в приложении «Файлы» на iPhone, в FinRoad открой **Ещё → Выбрать файл FinRoad** и выбери этот же файл в iCloud Drive.

Доставка изменений через iCloud может занять время. На iPhone обмен проверяется, пока приложение открыто.

При конфликте приложение предлагает выбрать одну версию плана и сохраняет копии; автоматического объединения правок нет. Доступны импорт и экспорт. Сохраняй независимые резервные копии. Подробности и ограничения — в инструкциях приложений и [описании архитектуры](docs/architecture.md).

## Разработка

Исходники находятся в `app/`, `macos/` и `ios/`. Для регрессионных проверок выполни `node --test tests/*.test.cjs`; дополнительные проверки синхронизации и финансового ядра описаны в инструкциях платформ. Для тестирования используй вымышленный план и отдельный файл.

GitHub Pages публикует `index.html` из `main`. Демо загружает финансовое ядро из `app/`, а мобильный интерфейс — из `web/`. `FinRoad.html` — прежняя самостоятельная версия для локального запуска.
