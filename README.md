# FinRoad

FinRoad — приложение для планирования доходов, расходов и долгов с прогнозом остатка. Версии для Mac и iPhone работают с локальными данными и могут обмениваться планом через общий файл в iCloud Drive, без отдельной регистрации в FinRoad.

**[Попробовать демо](https://sad-jack.github.io/FinRoad/)** — в браузере используются вымышленные данные; изменения сбрасываются при перезагрузке.

## Приложения

- **Mac:** открой `output/FinRoad.app` или собери приложение командой `./macos/build.sh`. Нужны инструменты командной строки Apple и Swift. [Инструкция для macOS](macos/README.md).
- **iPhone:** открой `ios/FinRoad.xcodeproj` в Xcode, выбери команду подписи и Bundle Identifier и установи приложение на устройство. Для сборки нужен весь репозиторий: мобильное приложение использует общее финансовое ядро. [Инструкция для iPhone](ios/README.md).

## Данные и синхронизация

На Mac план хранится в `~/Library/Application Support/FinRoad/`, на iPhone — в контейнере приложения. Чтобы обмениваться изменениями, подключи на Mac папку в iCloud Drive и выбери на iPhone тот же файл `FinRoad-sync.json`. iCloud доставляет изменения между устройствами с задержкой; на iPhone обмен проверяется при открытом приложении, работа в фоне не гарантирована.

При конфликте приложение предлагает выбрать одну версию плана и сохраняет копии; автоматического объединения правок нет. Доступны импорт и экспорт. Сохраняй независимые резервные копии. Подробности и ограничения — в инструкциях приложений и [описании архитектуры](docs/architecture.md).

## Разработка

Исходники находятся в `app/`, `macos/` и `ios/`. Для регрессионных проверок выполни `node --test tests/*.test.cjs`; дополнительные проверки синхронизации и финансового ядра описаны в инструкциях платформ. Для тестирования используй вымышленный план и отдельный файл.

`FinRoad.html` сохранён как прежняя браузерная версия и не является источником сборки приложений. Демонстрационный сайт остаётся отдельной HTML-версией.
